🙋 想要做什麼：mau（想／要）

這堂課會學印尼語的「mau」，意思是「想」或「要」。我們會先認識「我們、他們、他」和幾個常用動詞，再一步一步組成完整的句子，最後還有可以滑動複習的單字卡。

💡 點擊 🔊 或單字，可以使用手機或瀏覽器的語音功能聽印尼語發音。

👀 看圖選答案：我們、他們、他

根據中文，選出最能代表那個人稱的圖片。

👀 看圖選答案：動詞

根據中文，選出代表那個動作的圖片。

🧩 排排看：主詞 + mau + 動詞

主詞 + mau + 動詞
「mau」＝ 想／要（口語常用）。例如：Saya mau makan ＝ 我想吃。
Saya（我）比較正式，口語也常說 aku。

👀 看圖選答案：名詞與指示詞

這些是等一下句子裡會用到的單字。

🧩 排排看：主詞 + mau + 動詞 + 受詞

主詞 + mau + 動詞 + 受詞
受詞放在動詞後面，跟中文的順序一樣。

👀 看圖選答案：地點與活動

根據中文，選出正確的圖片。

🧩 排排看：加上地點（di / ke）

主詞 + mau + 動詞 + 受詞 + di/ke + 地方

「di」相當於中文的「在」，用來表示動作或事情發生的地點。

「ke」則表示前往某個地方的「目的地」，通常用在表示移動、前往某個地方的情況。

👀 看圖選答案：這裡與那裡

看看人和地點之間的距離。

🧩 排排看：sini 與 sana

注意：第二句沒有 mau，意思是「他在那裡吃」（已經在做的事）。

👀 看圖選答案：gak 與 pergi

「gak」是口語的否定詞，正式說法是 tidak。

🧩 排排看：不想（gak mau）

主詞 + gak + mau + 動詞 + 受詞 + ke/di + 地點
gak 放在 mau 前面，表示「不想」。

🧩 排排看：用 gak 問問題

主詞 + mau + 動詞 + 受詞 + ke/di + 地點 + gak?
句尾的 gak 相當於中文的「嗎／要不要」。
Kamu mau makan gak? ＝ 你想吃嗎？（你想不想吃？）
